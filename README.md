# Pricing Cards Section

## Task 4 – Pricing Cards Section

A responsive pricing cards section created using **HTML, CSS, and JavaScript**. The project displays different pricing plans with their prices, features, descriptions, and interactive buttons.

## 🚀 Features

* Three pricing plans:

  * Basic
  * Pro
  * Premium
* Responsive design
* Mobile-friendly layout
* Hover effects on pricing cards
* "Most Popular" label for the Pro plan
* Feature lists for each plan
* Interactive plan selection buttons
* JavaScript alert when a plan is selected
* Clean and simple user interface

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## 💻 How to Run

1. Download or clone the project.
2. Open the project folder in VS Code.
3. Make sure all four files are in the same folder.
4. Open `index.html` in a web browser.

You can also use the **Live Server** extension in VS Code to run the project.

## 📱 Responsive Design

The website is designed to work on:

* Desktop
* Laptop
* Tablet
* Mobile phones

CSS media queries automatically adjust the pricing cards according to the screen size.
